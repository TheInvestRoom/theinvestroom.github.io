Les MCP pour l'architecture

La liste des connecteurs Claude pour tes logiciels, et comment les installer

Mis à jour le 26 octobre 2026
Un MCP (Model Context Protocol), c'est une prise qui branche une IA comme Claude sur un logiciel : elle peut alors lire ta maquette, et agir dedans à ta demande. Voici ceux qui existent pour l'architecture, du plus officiel au plus expérimental.

Les MCP par logiciel

Le serveur MCP d'Autodesk pour Revit 2027, en aperçu technique (encore en développement). C'est la voie recommandée si tu es sur Revit 2027.

Excel, PowerPoint, Photoshop, Notion, Figma…connecteurs

Pour la suite du projet (tableaux de surfaces, planches de présentation, retouches), regarde le répertoire de connecteurs intégré à Claude : Paramètres › Connecteurs. Claude sait aussi produire directement des fichiers Excel et PowerPoint. La disponibilité dépend de ton offre Claude.

Installer un MCP en 5 étapes

  1. Installe l'application Claude Desktop (Windows ou Mac) et connecte-toi.
  2. Connecteur prêt à l'emploi : ouvre Paramètres › Connecteurs, clique sur « + », puis choisis-le dans le répertoire ou colle l'adresse du serveur.
  3. Extension locale (fichier .mcpb) : double-clique sur le fichier, puis clique sur « Installer » dans le panneau Extensions.
  4. Serveur communautaire (Revit, Rhino, SketchUp…) : installe d'abord son plug-in dans le logiciel (pyRevit, extension SketchUp, add-on Tapir…), puis ajoute le serveur à Claude en suivant le README du projet.
  5. Ouvre ton projet, relance Claude et vérifie que les nouveaux outils apparaissent. Teste avec une demande simple : « Liste les niveaux de ma maquette ».

3 prompts pour commencer

Dans ma maquette Revit, fais une nomenclature de toutes les portes avec leur niveau, leurs dimensions et leur degré coupe-feu.
Dans Rhino, propose trois variantes de toiture pour le volume sélectionné : une à deux pans, une plate végétalisée, une en sheds.
Récupère les surfaces des pièces de ma maquette, fais-en un tableau Excel par niveau, puis une planche PowerPoint de synthèse.
Travaille toujours sur une copie de ton projet. Les serveurs communautaires ne sont pas des produits officiels : lis leur README (et leur page sécurité) avant de les brancher, garde un œil sur ce que l'IA modifie, et ne lui confie pas de données confidentielles de tes clients. Les outils évoluent très vite : informations vérifiées le 26 octobre 2026.
